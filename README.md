# Лабораторная работа № 1

## Разведочный анализ данных с помощью PySpark

**Датасет:** Steam Games Dataset

---

### Цель и задачи работы

1. Познакомиться с понятием «большие данные» и способами их обработки.
2. Познакомиться с инструментом `Apache Spark` и возможностями, которые он предоставляет для обработки больших данных.
3. Получить навыки выполнения разведочного анализа данных с использованием `pyspark`.

---

### Постановка задачи

Требуется провести разведочный анализ табличного датасета объёмом от нескольких сотен мегабайт средствами `Apache Spark` (PySpark). В ходе работы необходимо:

- определить типы признаков в датасете;
- выявить и устранить пропущенные значения;
- выявить и устранить выбросы;
- рассчитать статистические показатели признаков (средние, квартили, стандартное отклонение);
- визуализировать распределения наиболее важных признаков;
- рассчитать корреляции между числовыми признаками;
- сформулировать выводы по результатам анализа.

---

### Описание выбранного датасета

Для анализа выбран датасет **Steam Games Dataset**, размещённый на платформе Kaggle:

> **Ссылка:** https://www.kaggle.com/datasets/mexwell/steam-games-dataset

**Краткое описание:** 
Датасет содержит метаданные для более чем 136 000 игр из Steam, собранные из открытых источников и обновляемые ежедневно. Включает информацию о ценах, разработчиках, издателях, жанрах, категориях, отзывах, времени игры и другие характеристики.

**Основной файл:** `steam_games.csv` — около 939 МБ, что соответствует требованию «от нескольких сотен мегабайт».

**Ключевые столбцы:**

| Название столбца          | Расшифровка                                                                 |
|---------------------------|-----------------------------------------------------------------------------|
| `app_id`                  | Уникальный идентификатор приложения Steam                                   |
| `name`                    | Название игры                                                               |
| `release_date`            | Дата релиза (формат YYYY-MM-DD)                                             |
| `price`                   | Текущая цена игры в USD                                                     |
| `estimated_owners`        | Оценочный диапазон количества владельцев (по данным SteamSpy)               |
| `developers`              | Список разработчиков                                                        |
| `publishers`              | Список издателей                                                            |
| `genres`                  | Список жанров                                                               |
| `categories`              | Список категорий Steam (например, Single-player, Co-op, Steam Achievements) |
| `positive` / `negative`   | Количество положительных и отрицательных отзывов                            |
| `recommendations`         | Количество рекомендаций                                                     |
| `average_playtime_forever`| Среднее общее время игры в минутах                                          |

### Ход выполнения работы

#### Часть 1. Очистка данных (`1_Data_cleansing_steam.ipynb`)

**Что сделано:**

1. **Загрузка данных.** CSV-файл `steam_games.csv` загружен в `Spark DataFrame`.

2. **Выбор признаков.** Из 42 столбцов оставлены 15 наиболее значимых для анализа: `app_id`, `name`, `release_date`, `price`, `estimated_owners`, `developers`, `publishers`, `genres`, `categories`, `positive`, `negative`, `recommendations`, `average_playtime_forever`, `steam_store_available`, `steam_spy_available`.

3. **Приведение типов данных.** Все столбцы изначально имели строковый тип. Выполнено приведение:
   - `price`, `average_playtime_forever` → `float`;
   - `positive`, `negative`, `recommendations`, `release_year` → `integer`;
   - `steam_store_available`, `steam_spy_available` → `boolean`;
   - `developers`, `publishers`, `genres`, `categories` → `array<string>`.

4. **Очистка массивов.** Столбцы-массивы содержали мусор: фигурные скобки, кавычки, префиксы `id:`, `description:`, а также чисто числовые значения (id жанров). Выполнена очистка:
   - удалены символы `{}[]"`;
   - удалены префиксы `id:`, `description:`, `name:`;
   - отфильтрованы пустые и чисто числовые элементы.

5. **Удаление строк с `NULL` в `release_year`.** Строки без корректной даты релиза удалены.

6. **Сохранение результата.** Очищенный датафрейм сохранён в `steam_games_cleaned.parquet`.

**Результат:** чистый Parquet-файл, готовый к разведочному анализу.

#### Часть 2. Разведочный анализ (`2_Exploratory_analysis_steam.ipynb`)

**Что сделано:**

1. **Загрузка очищенных данных** из `steam_games_cleaned.parquet` в `Spark DataFrame`.

2. **Типы признаков:**
   - **Количественные:** `price`, `positive`, `negative`, `recommendations`, `average_playtime_forever`, `num_genres`, `num_categories`, `release_year`;
   - **Категориальные (массивы):** `genres`, `developers`, `publishers`, `categories`;
   - **Категориальный (скалярный):** `estimated_owners`.

3. **Пропущенные значения.** Подсчитано количество `NULL` в каждом столбце. Для количественных признаков пропуски заполнены средними значениями; для строковых — значением `"Unknown"`; для массивов — пустыми массивами; для булевых — `False`.

4. **Выбросы.** Для количественных признаков построены диаграммы «ящик с усами», рассчитаны границы IQR. Экстремальные значения отфильтрованы:
   - `price` ≤ 100 USD;
   - `recommendations` ≤ 5000;
   - `average_playtime_forever` ≤ 10 000 минут.

5. **Статистические показатели.** Для количественных признаков рассчитаны: минимум, среднее, стандартное отклонение, первый квартиль, медиана, третий квартиль, максимум.

6. **Визуализация распределений:**
   - гистограммы с KDE для количественных признаков (`price`, `positive_ratio`, `recommendations`, `average_playtime_forever`, `release_year`);
   - barplot для категориальных признаков и массивов (`genres`, `developers`, `publishers`, `categories`, `num_genres`, `num_categories`).

7. **Корреляционный анализ.** Построена матрица корреляций Пирсона для количественных признаков: `price`, `positive`, `negative`, `recommendations`, `average_playtime_forever`, `num_genres`, `num_categories`, `positive_ratio`, `release_year`.

8. **Сохранение результата.** Обработанный датафрейм сохранён в `steam_games_processed.parquet`.

### Результаты анализа

#### 1. Цены на игры

- Большинство игр имеют цену до 20 USD.
- Около 20% игр распространяются бесплатно.
- Медианная цена платной игры — около 5–10 USD.
- Распределение цен имеет ярко выраженную правостороннюю асимметрию: дорогие игры (более 50 USD) встречаются редко.

#### 2. Жанры

- Наиболее популярные жанры: **Indie**, **Action**, **Casual**, **Adventure**.
- Одна игра может относиться к нескольким жанрам одновременно (в среднем 2–3 жанра на игру).
- Жанр `Indie` доминирует по количеству игр, что отражает рост инди-сегмента на Steam.

#### 3. Разработчики и издатели

- Большинство игр выпущено небольшими студиями (менее 10 игр в портфеле).
- Топ-разработчики имеют сотни игр; среди них встречаются как крупные издатели, так и активные инди-студии.
- Распределение количества игр по разработчикам имеет степенной характер (закон Ципфа).

#### 4. Отзывы и рекомендации

- Средний процент положительных отзывов — около 80–90%.
- Медианное значение `positive_ratio` выше 85%, что говорит о лояльности аудитории Steam.
- Распределение количества рекомендаций сильно смещено вправо: большинство игр имеют менее 100 рекомендаций, но есть игры с тысячами рекомендаций.

#### 5. Временной тренд

- Количество выпускаемых игр растёт с каждым годом.
- Пик выпуска приходится на 2020–2023 годы, что связано с ростом рынка инди-игр и последствиями пандемии.
- Старые игры (до 2000 года) встречаются редко.

#### 6. Корреляции

- **Сильная положительная корреляция** между `positive` и `recommendations` (≈ 0.9) — логично, так как рекомендации формируются на основе отзывов.
- **Средняя положительная корреляция** между `positive` и `negative` — популярные игры получают больше отзывов обоих типов.
- **Слабая корреляция** между `price` и популярностью (`positive`, `recommendations`) — бесплатные игры не всегда популярнее платных.
- **Слабая корреляция** между `num_genres`, `num_categories` и ценой/популярностью — количество жанров слабо влияет на успех игры.
- **Отрицательная корреляция** между `release_year` и `average_playtime_forever` — старые игры имеют больше накопленного времени игры.

### Выводы

1. **Датасет пригоден для разведочного анализа.** После очистки данных (удаление мусора в массивах, приведение типов, удаление `NULL`) датасет содержит 136 000+ игр с корректными признаками.

2. **Основные закономерности рынка Steam:**
   - Рынок смещён в сторону недорогих и бесплатных игр;
   - Инди-игры доминируют по количеству;
   - Большинство игр получают высокий процент положительных отзывов.

3. **Корреляционный анализ** подтвердил ожидаемые зависимости (отзывы ↔ рекомендации) и показал отсутствие сильной связи между ценой и популярностью.

4. **Проблемы данных:**
   - Столбцы-массивы требовали дополнительной очистки от мусора (id жанров, фигурные скобки);
   - Часть строк содержала `NULL` в `release_year`, что потребовало фильтрации;
   - Признак `estimated_owners` задан в виде диапазона строк, что затрудняет числовой анализ без дополнительной обработки.

5. **Перспективы дальнейшего анализа:**
   - Прогнозирование цены игры на основе жанров, разработчика и года выпуска;
   - Кластеризация игр по популярности и жанрам;
   - Анализ отзывов (NLP) для выявления факторов успеха игры.
